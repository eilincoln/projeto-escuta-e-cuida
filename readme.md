# 🌳 Projeto Escuta e Cuida

Plataforma digital de saúde mental desenvolvida em parceria com a **Universidade São Francisco (USF)** e o **PSF Jardim Galetto — Itatiba/SP**.

O projeto conecta profissionais da unidade de saúde a psicólogos formados que oferecem atendimento online a valor social, promovendo bem-estar, acolhimento e qualidade de vida.

---

## 🖥️ Demonstração

> Projeto estático — pode ser aberto diretamente no navegador via `index.html` ou hospedado em qualquer serviço de hosting estático (Vercel, Netlify, GitHub Pages).

---

## ✨ Funcionalidades

- Perfis individuais dos psicólogos com foto, CRP, abordagem e descrição
- Botão de contato direto via WhatsApp para cada profissional
- Filtro de psicólogos por abordagem terapêutica (Psicanálise, TCC, Humanista)
- Seção explicativa sobre as abordagens terapêuticas disponíveis
- Seção "Como funciona" com os 3 passos para agendamento
- Equipe do projeto e créditos de desenvolvimento
- Botão flutuante de voltar ao topo
- Animações de entrada com Intersection Observer
- Contador animado no hero
- Design responsivo para mobile e desktop

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica
- **CSS3** — variáveis CSS, animações, Grid e Flexbox
- **JavaScript (Vanilla)** — sem frameworks ou dependências externas
- **Google Fonts** — Cormorant Garamond + DM Sans

## 📌 Sobre o projeto

Este projeto foi idealizado por alunos do curso de **Psicologia da USF (9º Semestre)** como parte das atividades de extensão acadêmica, em articulação com o PSF Jardim Galetto.

Os atendimentos são realizados exclusivamente por **psicólogos formados e registrados no CRP**.

> Em caso de emergência de saúde mental, ligue para o **CVV: 188** (24h, gratuito).
